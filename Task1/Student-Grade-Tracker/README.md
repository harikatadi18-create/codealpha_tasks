# 🎓 Student Grade Tracker

A simple and interactive web-based Student Grade Tracker developed as part of the **CodeAlpha Java Programming Internship**.

The application allows users to add, manage, search, edit, delete, and view student academic records. It automatically calculates total marks, average marks, grades, and pass/fail status.

## ✨ Features

- ➕ Add new students
- 📚 Add multiple subjects and marks
- 🧮 Automatically calculate total and average
- 🏆 Automatically assign grades
- ✅ Calculate pass/fail status
- 🔍 Search students by name or roll number
- 👁️ View detailed student reports
- ✏️ Edit and update student records
- 🗑️ Delete student records
- 📊 Dashboard with class statistics
- 📈 Grade distribution
- 🥇 Top performer identification
- 💾 Data persistence using browser LocalStorage
- 📱 Responsive design

## 📊 Grading System

| Average | Grade |
|--------:|:-----:|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

**Pass Criteria:** Average marks ≥ 50
