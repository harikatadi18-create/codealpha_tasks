# 🏨 Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship.

The system allows users to search available hotel rooms, make reservations, simulate payments, view booking details, and cancel reservations.

## ✨ Features

- Search available rooms
- Room categorization
  - Standard
  - Deluxe
  - Suite
- Make hotel reservations
- Customer information management
- Check-in and check-out details
- Automatic total amount calculation
- Payment simulation
- Unique booking ID generation
- View booking details
- Cancel reservations
- Store booking information using File I/O
- Store website bookings using browser LocalStorage
- Object-Oriented Programming implementation
- Responsive web interface
