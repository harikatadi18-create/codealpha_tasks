# 🤖 Artificial Intelligence Chatbot

A Java-based Artificial Intelligence Chatbot developed as part of the CodeAlpha Java Programming Internship.

The chatbot uses Natural Language Processing (NLP) techniques such as text preprocessing and keyword-based intent detection to provide responses to frequently asked questions.

## ✨ Features

- 🤖 AI FAQ Chatbot
- 🧠 NLP-based text preprocessing
- 🎯 Keyword-based intent detection
- 💬 Interactive real-time conversation
- 📚 Frequently Asked Questions
- ☕ Java-based chatbot engine
- 💾 Chat history using File I/O
- 🌐 Modern web-based chatbot interface
- 📱 Responsive design
- 🧹 Clear chat functionality
- ⌨️ Enter-key message support
- ⚡ Typing indicator

## 🧠 Supported Topics
